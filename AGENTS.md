# Правила разработки и синхронизации JobHunter AI

## Автоматическая синхронизация с GitHub
* При любых доработках, изменениях логики, промптов или кода — сразу фиксировать изменения коммитом и пушить в удаленный репозиторий (`origin main`).
* **Безопасность прежде всего:** перед коммитом всегда проверять, что реальные API-токены, приватные ключи сервисных аккаунтов и персональные данные заменены на плейсхолдеры.
