# Настройка Google Sheets для JobHunter AI

Сценарий использует единую Google Таблицу с разделением на две вкладки:
1. **`JobHunt_РОП`** — основная вкладка для одобренных вакансий (`READY`).
2. **`JobHunt_Rejected`** — техническая вкладка для отклонённых вакансий (`REJECTED`).

---

## 1. Структура столбцов (одинаковая для обеих вкладок)

Создайте в вашей таблице две вкладки и вставьте следующие заголовки в строку 1 (столбцы A - I):

| Столбец | Поле | Описание |
|---|---|---|
| **A** | `vacancy_id` | Уникальный ID вакансии (числовой для HH, `TG_канал_номер` для Telegram) |
| **B** | `created_at` | Дата и время добавления (формат `YYYY-MM-DD HH:mm`) |
| **C** | `company` | Название компании / работодателя |
| **D** | `role` | Должность |
| **E** | `salary` | Зарплатная вилка или `Не указана` |
| **F** | `url` | Ссылка на вакансию / пост (в TG включает `@contact` если найден) |
| **G** | `status` | Статус (`READY` для основной вкладки, `REJECTED` для технической) |
| **H** | `pitch_or_reason` | Структурированная сводка (`🏢 Бизнес \| 💰 Доход \| 🎯 Задачи`) или причина отказа |
| **I** | `my_status` | Ваш личный статус отклика (`Откликнулся`, `Интервью`, `Отказ` и т.д.) |

---

## 2. Настройка сервисного аккаунта (Google Cloud Service Account)

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Включите **Google Sheets API** и **Google Drive API**.
3. Создайте сервисный аккаунт (**IAM & Admin ➔ Service Accounts ➔ Create Service Account**).
4. Создайте ключ JSON (**Keys ➔ Add Key ➔ Create new key ➔ JSON**) и сохраните его как `service_account.json`.
5. Откройте созданную Google Таблицу и **поделитесь ею с email сервисного аккаунта** с правами **Редактора** (Editor).
6. В n8n создайте Credentials типа **Google Service Account** и вставьте содержимое `service_account.json`.
